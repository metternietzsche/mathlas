# Mathlas

Práctica de matemática para la IA, como un juego: **Modo clase** (ejercicios con fichas, pistas y laboratorios) y **Modo historia** (siete capítulos, de la neurona de 1943 a varios agentes y el equilibrio de Nash).

Es una sola página que funciona en el teléfono. El progreso se guarda en el propio navegador.

Este repositorio solo publica la página ya armada; el código fuente vive en otro repositorio.
